1. Хяналттай төхөөрөмж

  • App: Flutter / React Native
  • Уналт илрүүлэлт (AI): 1D CNN / Random Forest

2. AI Сервер / Backend

3. Асрагчийн App

  • Үүрэг: Асран хамгаалагчид зориулсан хяналтын апп
  • Газрын зураг: Google Maps API
